# Backroom Bratzz Deluxe

A fast, comedic browser shooting game inspired by the chaos of a retail backroom.

Choose Alex or Riley-L, fire rubber bands, build streaks and combos, collect pizza, and survive the managers. The entire game is contained in one HTML file and runs without a build step.

## Play

Download `index.html` and open it in a modern browser.

## How to play

- Click, tap, or hold to fire blue rubber bands.
- Collect stars for bonuses.
- Avoid Rea-Rea: three hits and you are fired.
- Hit Jaxon three times to unlock Ninja for the current session.
- Collect three pizzas to activate a character special.

### Characters

- **Alex** — rapid-fire pizza special
- **Riley-L** — spread-shot pizza special
- **Ninja** — unlockable character who throws ninja stars

### Keyboard controls

| Action | Key |
|---|---|
| Shoot | Space |
| Pause | P |
| Restart | R |
| Fullscreen | F |
| Settings | , |
| Mute | M |

Touch and pointer controls are supported.

## Features

- Character selection and unlockable character
- Score, streak, combo, warning, and power systems
- Multiple manager behaviors
- Character-specific specials
- Settings, sound controls, pause, restart, and fullscreen
- Responsive canvas for desktop and mobile browsers
- No dependencies or installation
